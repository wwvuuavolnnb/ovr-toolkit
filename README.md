## 🕹️ Overview

OVR Toolkit pins desktop windows, browsers, and media controls inside VR as interactive overlays, accessible via a customizable wrist-mounted control panel.

Whether you're a newcomer or a veteran, OVR Toolkit provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Window Pinning** | Attach any desktop window to a fixed VR space position |
| **Wrist Menu** | Quick-access panel on your wrist for common controls |
| **Media Controls** | Playback controls for Spotify, VLC, and system audio |
| **Keyboard Overlay** | Virtual keyboard for typing inside VR without removing headset |
